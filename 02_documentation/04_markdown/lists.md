### 📋 Markdown Lists  

Lists in Markdown help organize information into **ordered** (numbered) or **unordered** (bulleted) structures. They make documentation cleaner and easier to follow.  

---

## 🔑 Types of Lists  

- **Unordered Lists** → Use `-`, `*`, or `+` before items.  
  ```markdown
  - Item A
  - Item B
  - Item C
  ```
  **Output:**    
  - Item A  
  - Item B  
  - Item C  

- **Ordered Lists** → Use numbers followed by a period.  
  ```markdown
  1. Step One
  2. Step Two
  3. Step Three
  ```
  **Output:**   
  1. Step One  
  2. Step Two  
  3. Step Three  

- **Nested Lists** → Indent with two spaces or a tab.  
  ```markdown
  - Main Item
    - Sub Item
    - Sub Item
  ```
  **Output:**    
  - Main Item  
    - Sub Item  
    - Sub Item  

- **Task Lists (GFM)** → Use `- [ ]` for unchecked and `- [x]` for checked tasks.  
  ```markdown
  - [ ] Install PostgreSQL
  - [x] Configure Database
  - [ ] Import Data
  ```
  **Output:**    
  - [ ] Install PostgreSQL  
  - [x] Configure Database  
  - [ ] Import Data  

---

## 🌟 Best Practices  

- **Use unordered lists** for general notes.  
- **Use ordered lists** for step‑by‑step instructions.  
- **Use nested lists** to break down details.  
- **Use task lists** for project tracking in GitHub or VS Code.
