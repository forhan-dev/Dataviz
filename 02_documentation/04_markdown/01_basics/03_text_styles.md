### ✍️ Markdown Text Formatting  

Markdown provides simple ways to style text for emphasis and clarity. These formatting options make documentation more readable without complex syntax.  

---

## 🔑 Core Formatting Styles  

- **Bold** → `**text**`  
  Example: 
  ```markdown
  **Important Note**
  ```
  Output:    
  **Important Note**  

- **Italic** → `*text*` or `_text_`  
  Example:  
  ```markdown
  *Emphasis*
  ```  
  Output:  
  *Emphasis*  

- **Bold + Italic** → `***text***`  
  Example:  
  ```markdown
  ***Strong Emphasis***
  ```  
  Output:   
  ***Strong Emphasis***  

- **Strikethrough** → `~~text~~`  
  Example:  
  ```markdown
  ~~Deprecated Command~~
  ```  
  Output:  
  ~~Deprecated Command~~  

- **Inline Code** → `` `code` ``  
  Example:  
  ```markdown
  Query `SELECT * FROM users;`
  ```  
  Output:   
  Query `SELECT * FROM users;`  

---

## 🌟 Best Practices  

- **Use bold** for critical points.  
- **Use italic** for emphasis or tips.  
- **Use strikethrough** to mark deprecated commands.  
- **Use inline code** for commands, SQL queries, or filenames.  
- Avoid overusing formatting — keep it clean and minimal.
