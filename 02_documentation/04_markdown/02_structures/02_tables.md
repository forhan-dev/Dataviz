### 📊 Markdown Tables  

Tables in Markdown let you organize data into **rows and columns**. They’re especially useful for documentation, comparisons, and structured notes.  

---

## 🔑 Basic Syntax  

```markdown
| Column 1 | Column 2 |
|----------|----------|
| Data A   | Data B   |
| Data C   | Data D   |
```

**Output:**  
| Column 1 | Column 2 |
|----------|----------|
| Data A   | Data B   |
| Data C   | Data D   |

---

## 📊 Alignment Options  

You can align text in columns using colons `:`:  

```markdown
| Left Align | Center Align | Right Align |
|:-----------|:------------:|------------:|
| Apple      | Banana       | Cherry      |
| Dog        | Cat          | Bird        |
```

**Output:**  
| Left Align | Center Align | Right Align |
|:-----------|:------------:|------------:|
| Apple      | Banana       | Cherry      |
| Dog        | Cat          | Bird        |

---

## 🌟 Best Practices  

- **Use tables** for structured data.  
- Keep column headers **short and clear**.  
- Use **alignment** for readability.  
- Combine with **inline code** for technical examples.  
- Avoid overly complex tables — Markdown is best for simple structures.
